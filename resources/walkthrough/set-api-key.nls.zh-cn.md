open Copilot Chat 使用你自己的 New API Bearer Token，从 New API 部署动态发现模型。

推荐使用命令面板设置，密钥会保存到 VS Code SecretStorage。也可以在扩展设置中填写 `open-copilot.apiKey`，但该设置会以明文保存在本机。

- `Cmd/Ctrl + Shift + P`：打开命令面板
- `Open Copilot：设置 Bearer Token`：设置或更新 Bearer Token
- `Open Copilot：清除 Bearer Token`：移除 Bearer Token
- `Open Copilot：打开 Token 文档`：打开 New API Token 文档
